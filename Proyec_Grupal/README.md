# Sistema de inventario (HTML + CSS + jQuery + JS)

Plantilla general para cualquier emprendimiento.

## Estructura
- index.html        -> estructura de la página
- css/styles.css    -> estilos, modo día/noche y diseño responsivo
- js/app.js         -> lógica del inventario, filtros, validaciones y efectos jQuery

## Cómo usarlo
1. Descomprime la carpeta y abre index.html en el navegador (necesita internet para cargar jQuery y la tipografía).
2. Personaliza el negocio en js/app.js, objeto CONFIG (nombre, logo, moneda, datos de la empresa y redes sociales).
3. Los datos se guardan en el navegador (localStorage).

## Incluye
- Modo día/noche, menú hamburguesa, carrusel y tarjetas
- Filtros por categoría, estado, precio, búsqueda y favoritos
- Efectos jQuery: hide, show, slideToggle, fadeToggle, slideDown, slideUp, fadeIn, fadeOut
- Formularios con validación en tiempo real (producto, movimiento, contacto)
- Sección de contacto, datos formales y redes sociales
- Exportar inventario a CSV
